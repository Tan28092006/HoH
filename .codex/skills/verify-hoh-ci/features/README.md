# HoH CI verification map

Use the assigned candidate checkout and an exclusive test slot. Windows examples
pin `D:/HoH/.venv-hoh/Scripts/python.exe`. Scratch and evidence roots must be
outside protected data, installed-service and candidate paths. Each helper run
creates its own fresh child directory; proof survives cleanup.

Features:

- [Targeted lane](targeted-lane.md): real supported wrapper, source identity,
  one actual API/SQLite scenario and owned cleanup.
- [Fast lane](fast-lane.md): existing PR marker selection and retained inventory.
- [Full lane](full-lane.md): complete suite and branch coverage gate.
- [Evidence gate](evidence-gate.md): validate actual retained reports and reject
  incomplete, wrong-revision or excluded evidence.

Every feature lists its own entry points. One passed feature proves only that
feature. Record commands, revision, outcomes/exclusions and retained paths;
report unmet prerequisites explicitly. No retries, new skips or cached passes.
